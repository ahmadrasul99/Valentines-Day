# Quick Start - Deploy to Vercel

## Before You Deploy

1. **Add your images** to the project folder:
   - `proposal-image.jpg` - Your photo with flowers
   - `couple-photo.jpg` - Photo of you both together

2. **Optional: Customize names** in index.html (lines 18-19)

## Fastest Way to Deploy (Drag & Drop)

1. Visit: https://vercel.com/new
2. Sign in with GitHub, GitLab, or email
3. **Drag your entire project folder** onto the upload area
4. Click "Deploy"
5. Done! 🎉

Your site will be live at: `https://your-project-name.vercel.app`

## Alternative: Command Line

```bash
# Install Vercel CLI
npm install -g vercel

# Navigate to your project
cd /path/to/valentine-proposal

# Deploy
vercel

# For production deployment
vercel --prod
```

## Custom URL (Optional)

Want a custom domain like `valentine.shoaib.com`?

1. Go to your Vercel project dashboard
2. Settings → Domains
3. Add your domain and follow DNS instructions
